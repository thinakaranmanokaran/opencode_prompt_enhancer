# Synthesia Prompt — OpenCode Prompt Enhancer

## Main prompt (40-second ad)

```text
Create a 40-second product ad for a developer tool called OpenCode Prompt Enhancer.

WHAT IT IS
OpenCode Prompt Enhancer is a free, open-source plugin for OpenCode, a terminal-based AI coding agent. It adds one command: /enhance. A developer types a rough, vague request, and /enhance rewrites it into a clear, specific, actionable prompt — then shows the result in a scrollable modal where they can insert it, copy it, or retry it.

WHO IT'S FOR
Developers and technical teams already using AI coding agents. They know what they want, but they type short, vague prompts and get generic code back.

CORE PROMISE
One command turns "fix login" into a prompt with the goal, constraints, files involved, and a definition of done. Better prompt in, better code out.

KEY POINTS, IN ORDER
1. Vague prompts waste time with your AI coding agent.
2. /enhance rewrites the draft using the model and context already in the open session — no extra model setup.
3. The rewrite appears in a modal: Enter inserts it, C copies it, R retries.
4. It is configurable — role, tone, specialties, rules, examples, custom template — and works from the OpenCode home screen too.
5. Free and open source. Install with one command.

TONE
Confident, dry, developer-native. No hype, no exclamation marks, no "revolutionary" or "game-changing". A senior engineer showing a tool they actually use. Fast delivery, clean cuts, slightly witty.

VISUAL STYLE
Dark terminal aesthetic. Near-black background, off-white text, one hot orange accent. Monospace type for commands, clean sans-serif for headlines. Screen-UI focused. Subtle motion. No stock-photo office scenes, no people high-fiving.

STRUCTURE
Hook (0–3s): "You know what you want. Your prompt doesn't."
Problem (3–9s): a three-word prompt, generic output, wasted round-trip.
Reveal (9–15s): type /enhance, spinner runs.
Demo (15–27s): the rewritten prompt appears in a modal; insert, copy, retry.
Payoff (27–33s): split screen of vague vs. precise results.
CTA (33–40s): product name, "Sharper prompts, without the ceremony.", install command, website.

ENDING CARD TEXT
OpenCode Prompt Enhancer
Sharper prompts, without the ceremony.
opencode plugin add opencode-prompt-enhancer
thinakaranmanokaran.github.io/opencode_prompt_enhancer

FORMAT
16:9, 1080p, burned-in captions, calm minimal synth music under the voice.
```
